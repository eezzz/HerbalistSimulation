# 百草衡 · Herbalist Simulation

中药保健配伍模拟器（中英双语）。单个 HTML 文件，无需构建，直接用浏览器打开 `index.html` 即可。

A bilingual (Chinese / English) herbal wellness formula simulator. Single HTML file — open `index.html` in a browser.

## 功能 Features

- 99 味常用药材，剂量精确到 0.5 g，标注《中国药典》常用量
- 两种烹制方式：泡水（水温、焖泡时间）与煮（浸泡、后下、先煎、捣碎、烊化），估算溶出率、出汤量、浓度、口感与汤色
- 推演四气五味、五行（相生相克雷达图）、归经、功效构成、君臣佐使、体质契合
- 66 个经典保健方，分 12 类；识别 38 个经典配伍（含比例检查，如当归补血汤 5:1、交泰丸 10:1）
- 十八反、十九畏、相恶、孕期禁忌、有毒药材提醒
- 每日总量与疗程累积：建议最长连服天数，甘草酸、香豆素、咖啡因、糖的每日摄入估算
- 现代药理：主要成分与常见药物相互作用
- 一键中英文切换
